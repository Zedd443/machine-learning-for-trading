# Trading Learning System

Sistem belajar trading yang berorientasi pada bukti, pengujian, dan risk control — bukan koleksi indikator.

## Cara pakai
1. Mulai dari `docs/01_curriculum.md`.
2. Baca `docs/02_literature_map.md` untuk membedakan evidence, hipotesis, dan jargon.
3. Gunakan `docs/03_rulebook_v1.md` sebagai strategi baseline yang harus diuji, bukan dipercaya.
4. Catat trade di `data/journal_template.csv`.
5. Gunakan analyzer lokal untuk expectancy, profit factor, drawdown, losing streak, segmentasi, dan rule adherence.

## Prinsip
- Edge adalah hipotesis sampai lolos pengujian.
- Loss sesuai rule bukan otomatis trade buruk.
- Profit dari pelanggaran rule bukan otomatis trade bagus.
- Ukur hasil dalam R-multiple sebelum rupiah/dolar.
- Jangan menaikkan risiko untuk mengejar target harian.
- Jangan mengoptimalkan terlalu banyak parameter pada sampel yang sama.
